PRECIO DE CIRCUITO - APLICACIÓN LOCAL

ARCHIVOS:
- index.html
- style.css
- script.js

USO EN WEBCODE:
1. Descomprime precio_circuito_app.zip.
2. Crea una carpeta/proyecto llamado precio_circuito_app.
3. Coloca dentro los 3 archivos.
4. Abre index.html con la vista previa de WebCode.

FUNCIONAMIENTO:
- Escribe una cantidad en la columna amarilla.
- Precio total de cada fila = Precio x Cantidad.
- PRECIO TOTAL = suma de todos los precios totales.
- MONTO / COBRAR = PRECIO TOTAL x 3.
- El botón LIMPIAR borra todas las cantidades.
- No usa Internet, servidor, API ni base de datos.

NOTA:
Esta versión está hecha como aplicación web local. Si quieres un APK instalable de Android posteriormente, hay que empaquetar estos mismos archivos como aplicación Android.
